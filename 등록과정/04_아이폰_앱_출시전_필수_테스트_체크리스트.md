# 04. 아이폰(iOS) 앱 출시 전 필수 테스트 체크리스트

하루여행(OneDay Trip) iOS 하이브리드 앱의 안정성과 사용자 경험, 그리고 Apple 앱스토어 심사 통과를 위해 **출시 전 실제 iPhone(또는 시뮬레이터)에서 반드시 직접 검증해야 하는 종합 테스트 체크리스트**입니다.

---

## 📋 1. 핵심 기능 테스트 (Functional QA)

### 📍 [1] 실시간 위치 기반 서비스 (GPS & Geolocation)
- [ ] **최초 권한 팝업**: 앱 첫 실행 시 `"내 주변 가볼 만한 곳과 맛집 추천..."` 시스템 권한 팝업 노출 확인
- [ ] **내 위치 탐색**: 홈 및 지도 화면에서 **"내 주변" / "내 위치"** 버튼 탭 시 현재 GPS 좌표로 지도 중심 이동 확인
- [ ] **도보/차량 거리 계산**: 현재 위치 기준으로 주변 맛집/명소의 도보 소요 시간(예: "도보 약 2분") 정상 계산 확인
- [ ] **권한 거부 시 대응**: 설정에서 위치 권한을 껐을 때 크래시 없이 "위치 권한이 필요합니다" 안내 또는 재시도 힌트가 노출되는지 확인

### 🗺️ [2] 외부 지도 앱 연동 (`LSApplicationQueriesSchemes`)
- [ ] **네이버 지도 (`nmap://`)**:
  - 네이버 지도 앱 설치 기기: [길찾기] 버튼 탭 시 네이버 지도 앱이 즉시 실행되고 출발지/목적지가 입력되는지 확인
  - 미설치 기기: 네이버 지도 웹 페이지 또는 App Store 다운로드 페이지로 자연스럽게 이동하는지 확인
- [ ] **카카오맵(`kakaomap://`) / 티맵(`tmap://`)**: 연동 링크 클릭 시 해당 내비 앱 실행 여부 확인
- [ ] **전화(`tel:`), 메일(`mailto:`)**: 장소 상세의 전화번호 터치 시 iOS 통화 다이얼로그 호출 확인

### 💾 [3] 파일 다운로드 및 시스템 공유 (`DOWNLOAD_BLOB`)
- [ ] 여행 일정표 또는 이미지 다운로드 시 iOS 기본 공유 시트(`UIActivityViewController`) 호출 확인
- [ ] "이미지 저장"(사진 보관함) 또는 "파일에 저장" 선택 시 정상 저장되는지 확인
- [ ] iPad 환경에서 팝오버(Popover) 크래시 없이 중앙 앵커로 정상 표시되는지 확인

### 📷 [4] 카메라 및 사진 보관함 업로드
- [ ] 사진 첨부(`input[type="file"]`) 탭 시 "사진 찍기", "사진 보관함", "파일 선택" 옵션 노출 확인
- [ ] 사진 촬영 및 앨범 사진 선택 후 웹 화면에 이미지가 정상 업로드되는지 확인

### 🌐 [5] 다국어(i18n) 시스템 언어 자동 감지
- [ ] iPhone 설정 ➔ 일반 ➔ 언어 및 지역에서 시스템 언어를 **영어(English)** 또는 **일본어(日本語)**로 변경 후 앱 재실행
- [ ] 앱 UI 텍스트 및 메뉴가 해당 언어로 자동 전환되는지 확인 (`GET_DEVICE_LANGUAGE`)

### 🔐 [6] 로그인 / 로그아웃 및 계정 삭제
- [ ] 로그인 후 새로고침/앱 재실행 시 세션이 정상 유지되는지 확인
- [ ] 로그아웃 시 `WKWebsiteDataStore` 쿠키/캐시 삭제 후 초기 홈 화면으로 안전하게 리디렉션되는지 확인
- [ ] **회원 탈퇴 (App Store 필수 규정)**: 마이페이지(MY) ➔ 회원 탈퇴 진행 시 정상 처리 및 안내 팝업 확인

## 📱 2. UI / UX 및 인터랙션 테스트

### 📐 [1] Safe Area (노치, 다이내믹 아일랜드, 홈 인디케이터)
- [ ] 최신 iPhone(다이내믹 아일랜드 기종) 상단바와 웹 상단 헤더가 겹치지 않는지 확인
- [ ] 하단 홈 인디케이터(가로줄 바) 영역이 웹 하단 네비게이션 탭바를 가리지 않는지 확인
- [ ] 가로 모드(Landscape) 회전 시(지원 기종) 레이아웃 깨짐이 없는지 확인

### ⌨️ [2] 키보드 입력 대응 (Keyboard Avoidance)
- [ ] 장소 검색창 또는 로그인 입력 필드 터치 시 가상 키보드가 자연스럽게 올라오는지 확인
- [ ] 키보드가 입력 필드를 가리지 않고 화면이 적절히 위로 스크롤되는지 확인
- [ ] 화면 빈 공간 터치 시 키보드가 정상적으로 내려가는지 확인

### 👈 [3] 제스처 인터랙션
- [ ] 화면 좌측 가장자리에서 오른쪽으로 스와이프 시 이전 페이지로 뒤로가기 동작 확인 (`allowsBackForwardNavigationGestures = true`)
- [ ] 상단 당겨서 새로고침(Pull-to-Refresh) 또는 스크롤 바운스가 자연스럽게 동작하는지 확인

### 🌓 [4] 다크 모드 (Dark Mode) 테스트
- [ ] iOS 제어 센터에서 **다크 모드** 활성화
- [ ] 시스템 배경색(`systemBackground`) 및 웹뷰 배경 간 색상 충돌이나 글자 가독성 저하가 없는지 확인

## ⚡ 3. 예외 상황 및 안정성 테스트

- [ ] **네트워크 단절 (비행기 탑승 모드)**:
  - 인터넷이 끊긴 상태에서 앱 실행 시 크래시 없이 "페이지를 로드할 수 없습니다" 시스템 얼럿 노출 확인
- [ ] **백그라운드 전환 및 복귀**:
  - 앱 사용 중 홈으로 나갔다가 다시 들어왔을 때 화면이 하얗게 멈추거나 튕기지 않고 유지되는지 확인
- [ ] **메모리 경고(OOM)**:
  - 고해상도 지도 타일 및 사진을 장시간 탐색해도 메모리 누수로 앱이 꺼지지 않는지 확인

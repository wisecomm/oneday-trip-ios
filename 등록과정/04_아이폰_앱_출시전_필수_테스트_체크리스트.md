# 04. 아이폰(iOS) 앱 출시 전 필수 테스트 체크리스트

하루여행(OneDay Trip) iOS 하이브리드 앱의 안정성과 사용자 경험, 그리고 Apple 앱스토어 심사 통과를 위해 **출시 전 실제 iPhone(또는 시뮬레이터)에서 반드시 직접 검증해야 하는 종합 테스트 체크리스트**입니다.

---

## 🚨 1. 앱스토어 심사 통과를 위한 필수 체크 (최우선) — [검증 완료 ✅]

- [x] **회원 탈퇴(Account Deletion) 기능 확인 (가이드라인 5.1.1(v))**
  - **애플 필수 규정**: 계정 생성이 가능한 앱은 반드시 앱 내(마이페이지 등)에서 계정을 즉시 삭제/탈퇴할 수 있는 버튼과 플로우가 있어야 합니다. (없을 시 100% 심사 거절)
  - **테스트 방법 및 확인**: 로그인 후 마이페이지 ➡️ 회원 탈퇴 진행 시 정상 처리 및 안내 플로우 확인 완료.

- [x] **오프라인 / 네트워크 에러 대응**
  - **테스트 방법 및 확인**: 비행기 탑승 모드(Wi-Fi/데이터 OFF)에서 앱 실행 시 크래시 없이 "페이지를 로드할 수 없습니다" 시스템 네트워크 오류 얼럿 정상 표시 확인 완료.

- [x] **권한 요청 목적(Privacy Description) 일치 여부**
  - **테스트 방법 및 확인**: 위치(`NSLocationWhenInUseUsageDescription`), 카메라(`NSCameraUsageDescription`), 사진 보관함(`NSPhotoLibraryUsageDescription`) 권한 요청 문구가 실제 앱 내 사용 목적과 명확히 일치함 확인 완료.

## 🗺️ 2. 핵심 기능 테스트 (네이티브 브릿지 & 연동)

### [1] 현재 위치 및 주변 탐색 (방금 수정한 부분) — [검증 완료 ✅]
- [x] **내 위치 이동**: 지도 화면 우하단 "내 주변" / "내 위치" 버튼을 눌렀을 때 현재 GPS 위치로 지도가 정상 이동하는지 확인
- [x] **주변 탐색 로드**: 현재 위치 기준 도보 거리(예: "도보 약 2분") 및 주변 맛집/명소 목록이 정상 로드되는지 확인
- [ ] **위치 거부 시 대응**: iOS 설정에서 위치 권한을 '안 함'으로 껐을 때 안내 메시지가 적절히 노출되는지 확인

### [2] 외부 길찾기 지도 앱 연동 (`LSApplicationQueriesSchemes`)
- [ ] **네이버 지도 (`nmap://`)**:
  - 상세 페이지에서 "네이버 지도 길찾기" 클릭 시 네이버 지도 앱이 설치되어 있으면 앱이 바로 열리는지 확인
  - 네이버 지도 앱 미설치 시 앱스토어 또는 네이버 웹 지도로 자연스럽게 전환되는지 확인
- [ ] **카카오맵(`kakaomap://`) / 티맵(`tmap://`)**: 연동 링크 클릭 시 해당 내비 앱 실행 여부 확인
- [ ] **전화(`tel:`), 메일(`mailto:`)**: 장소 전화번호 터치 시 iOS 전화 걸기 다이얼로그 노출 확인

### [3] 파일 다운로드 및 공유 (`DOWNLOAD_BLOB`)
- [ ] 여행 일정표 또는 이미지 다운로드 시 iOS 기본 공유 시트(`UIActivityViewController`)가 정상 호출되는지 확인
- [ ] 공유 시트에서 "이미지 저장"(사진 보관함) 또는 "파일에 저장" 선택 시 실제 파일이 정상 저장되는지 확인
- [ ] iPad 환경에서 팝오버 앵커 크래시 없이 화면 중앙에 안정적으로 뜨는지 확인

### [4] 카메라 및 사진첩 첨부
- [ ] 장소 후기 사진 등록이나 프로필 사진 변경 시 `<input type="file">` 탭했을 때 카메라 촬영 및 사진 보관함 선택창이 정상 호출되는지 확인
- [ ] 촬영한 사진 또는 앨범 사진 선택 후 웹 화면에 정상 업로드되는지 확인

### [5] 다국어(i18n) 자동 감지 (`GET_DEVICE_LANGUAGE`)
- [ ] iPhone 설정 ➡️ 일반 ➡️ 언어 및 지역에서 시스템 언어를 **일본어** 또는 **영어**로 변경 후 앱 재실행
- [ ] 웹 UI가 해당 언어로 자동 전환되는지 확인

### [6] 로그아웃 및 세션 초기화
- [ ] 로그인 후 앱 재실행 시 세션이 정상 유지되는지 확인
- [ ] 로그아웃 버튼 탭 시 `WKWebsiteDataStore` 쿠키/캐시가 정리되고 로그인 화면 또는 초기 홈으로 정상 리디렉션되는지 확인

## 📱 3. iOS 화면 & UX 인터랙션 테스트

### [1] 노치 / 다이내믹 아일랜드 및 홈 바 (Safe Area)
- [ ] 최신 iPhone 기종(다이내믹 아일랜드) 및 홈 바(하단 가로줄) 영역에서 웹뷰 상하단 버튼이나 헤더 텍스트가 짤리거나 겹치지 않는지 확인
- [ ] 가로 모드(Landscape) 회전 시 화면 레이아웃 깨짐이 없는지 확인

### [2] 키보드 대응 (가림 현상 확인)
- [ ] 장소 검색창이나 로그인 인풋을 터치하여 가상 키보드가 올라왔을 때 입력 필드가 키보드에 가려지지 않고 스크롤되는지 확인
- [ ] 화면 빈 공간 터치 시 키보드가 정상적으로 내려가는지 확인

### [3] 좌우 스와이프 뒤로가기 제스처
- [ ] 화면 왼쪽 끝에서 오른쪽으로 스와이프했을 때 이전 페이지로 자연스럽게 이동하는지 확인 (`allowsBackForwardNavigationGestures = true`)
- [ ] 화면 상단 당겨서 새로고침(Pull-to-Refresh) 시 자연스러운 스크롤 바운스가 동작하는지 확인

### [4] 다크 모드 (Dark Mode) 테스트
- [ ] iOS 제어 센터에서 '다크 모드'를 켰을 때 상/하단 여백 배경색이나 글씨가 하얗게 묻히는 곳이 없는지 확인

## ⚡ 4. 예외 상황 및 안정성 테스트

- [x] **네트워크 단절 (비행기 탑승 모드)**: 인터넷이 끊긴 상태에서 앱 실행 시 크래시 없이 시스템 오류 얼럿 노출 확인
- [ ] **백그라운드 전환 및 복귀**: 앱 사용 중 홈으로 나갔다가 다시 들어왔을 때 화면이 멈추거나 튕기지 않고 유지되는지 확인
- [ ] **장시간 메모리 안정성**: 지도 탐색 및 고해상도 이미지를 연속으로 둘러보아도 메모리 누수로 꺼지지 않는지 확인
